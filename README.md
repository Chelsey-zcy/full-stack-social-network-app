> It's a small social network APP for developers powered by MERN stack, which enables users to create their profiles with fields such as education background and job experiences, etc.

> The App with basic functions such as sign up and login with JWT authentication.

> It also enables users to create and delete posts, comment, like and unlike posts with redux state managements techniques.

> Users can enter their GitHub name to display their five latest repos on their profiles by interacting with GitHub API.

## Prerequisites

- node 16.x

## Install

```sh
npm install
```

## Usage

Run the server

```sh
npm run start
```

Run the client side

```sh
cd client
npm run start
```
